To run audio_vesktop.py:
(made to run with OBS monitoring & output in the advance audio properties)
(and made to run to share screen in discord via Vesktop)

# Clean up old sinks first if needed
pactl unload-module module-null-sink

# 1. OBS monitors into this:
pactl load-module module-null-sink sink_name=OBS_Input sink_properties=device.description="OBS_Input"

# 2. Python outputs to this (Vesktop listens here):
pactl load-module module-null-sink sink_name=Vesktop_Out sink_properties=device.description="Vesktop_Out"

Then you can run the python script
